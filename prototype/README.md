# VitaDesa — Prototype UI/UX Mobile

Prototype lokal **Citizen Mobile App** VitaDesa. Ruang lingkup ini mengikuti Ketentuan Lomba THE ACE 2026 yang memperbolehkan satu platform, yaitu mobile. Stasiun VitaDesa tetap hadir sebagai konteks layanan fisik, tetapi tidak dirancang sebagai platform antarmuka terpisah.

## Menjalankan

Buka `index.html` langsung di browser modern. Tidak diperlukan instalasi, internet, backend, atau proses build.

## Interaksi utama

- Prototype menggunakan frame portrait 390 × 844 sebagai acuan tampilan.
- Pilih layar melalui menu “Lompat ke layar” atau jalankan alurnya dari splash.
- Alur utama mencakup onboarding, login, tracker harian, pemindaian QR stasiun, panduan pengambilan, voucher UMKM, analitik, notifikasi, dan profil keluarga.
- Klaim voucher mengurangi poin dan tersimpan di `localStorage`.
- Tombol “Reset demo” mengembalikan seluruh data simulasi.

## Catatan keselamatan

Prototype ini bukan perangkat medis. Kamera, data kesehatan, dan koneksi ke stasiun layanan merupakan simulasi visual. Aplikasi tidak mendiagnosis defisiensi mikronutrien; paket layanan digambarkan sebagai konfigurasi baku dari tenaga kesehatan.
