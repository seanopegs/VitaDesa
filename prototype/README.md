# VitaDesa — Prototype UI/UX

Prototype lokal untuk tiga touchpoint VitaDesa:

1. Citizen Mobile App
2. Kiosk IoT
3. Admin & UMKM Dashboard

## Menjalankan

Buka `index.html` langsung di browser modern. Tidak diperlukan instalasi, internet, backend, atau proses build.

## Interaksi utama

- Gunakan tiga tab di bagian atas untuk berpindah touchpoint.
- Pilih layar melalui menu “Lompat ke layar/langkah” atau jalankan alurnya dari awal.
- Alur kiosk mensimulasikan pemindaian, persetujuan, pembacaan sensor, dan dispensing.
- Klaim voucher mengurangi poin dan tersimpan di `localStorage`.
- Tombol “Reset demo” mengembalikan seluruh data simulasi.

## Catatan keselamatan

Prototype ini bukan perangkat medis. Kamera, sensor, data kesehatan, pembayaran, inventaris, dan dispenser adalah simulasi visual. Sensor tidak mendiagnosis defisiensi mikronutrien dan paket dosis digambarkan sebagai konfigurasi baku dari tenaga kesehatan.
